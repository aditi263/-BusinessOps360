
# BusinessOps360
### Enterprise Operations & IT Service Management Dashboard

BusinessOps360 is a portfolio project designed to help organizations monitor IT support tickets, business applications, employees, and operational performance through an interactive dashboard.

The project demonstrates how database management, business analytics, and IT service management can support operational decision-making.

## Technologies Used
- Python
- PostgreSQL
- SQLAlchemy
- Streamlit
- Pandas
- SQL

## Features

### 1. Executive Operations Dashboard
- Key performance indicators for tickets, applications, and employees
- Ticket status and priority analysis
- Interactive dashboard visualizations

### 2. IT Ticket Management
- Create new support tickets
- View and filter existing tickets
- Monitor ticket status and priority
- Ticket assignment interface (database update verification in progress)

### 3. SLA Monitoring
- Track ticket deadlines
- Identify overdue and approaching deadlines
- Monitor tickets requiring escalation

### 4. Operational Reporting
- Analyze IT service desk activity
- Generate CSV reports
- Support data-driven operational decisions

## Database Design
The application uses three core PostgreSQL tables:

- employees
- applications
- tickets

SQLAlchemy connects the Streamlit application to PostgreSQL.

## Project Status
**In Development**

The core dashboard, ticket creation interface, SLA monitoring, and reporting features have been implemented.

Additional work includes assignment verification, ticket resolution workflows, employee and application management, and deployment.
